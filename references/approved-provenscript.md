## Purpose

This library is the gold standard. Every new script written by this skill must be checked against the approved entries before writing begins.

Claude uses this file to understand:
1. What type of hooks are being approved
2. What tone and wording style is being used
3. How the body is structured
4. How the pain point is introduced
5. How the solution is presented
6. How the CTA is written
7. What phrases, angles, or formats are repeated
8. What lines should be reused, modified, or avoided
9. Which scripts feel strongest and why
10. How future scripts can match the approved style without sounding copied

**Rules for use:**
- Do not blindly copy approved scripts
- Use them as a style and strategy reference
- Salvage strong lines when useful — rewrite them when needed
- Keep new scripts fresh, sharp, and campaign-relevant
- If an approved script has a stronger structure than the current request, follow the stronger approved structure
- If an instruction conflicts with what usually works in this file, flag it briefly and suggest a better version
